up

UP

The portal passed the latest check cycle (every 30 seconds by default). That means DNS resolved, TCP connected to the portal port, and a short HTTP MPEG-TS pull succeeded — the same kind of stream request an IPTV player makes.

Use it. A card marked UP is currently working for playback. check-pass completed: N is how many cycles in a row it has stayed up.

down

DOWN

The portal failed the latest check cycle. One of DNS, TCP, or the MPEG-TS pull did not succeed. The red dns / tcp / ts flags show which step broke; reason is the specific code (for example dns_nxdomain, tcp_timeout, stream_blocked, stream_no_api).

Do not use it. Players will not get a working stream from this URL. fails N is how many cycles in a row it has been down. After 3 failures on a live URL, playlists on that host are swapped to a healthy standby. A down standby is never chosen for failover.

Cloudflare proxy

Cloudflare Proxy

The hostname resolves to a Cloudflare anycast IP (orange-cloud). Every HTTP request — including the MPEG-TS stream — goes through Cloudflare’s reverse proxy, not straight to the origin. Hover the badge on a card to see the nameserver hosts.

This is the more likely block. Cloudflare can 403, challenge, or TOS-disable IPTV while DNS and TCP still look fine. We have already seen that on a proxied host: player_api.php returned HTTP 403 with server: cloudflare. Failover will still use a proxied standby if nothing better is healthy, but only as a last resort after origin hosts and Cloudflare-NS-only hosts. If a live card is still UP, the stream is getting through right now — treat it as fragile, not preferred.

Cloudflare NS

Cloudflare NS

The domain’s nameservers are Cloudflare (eric.ns.cloudflare.com and similar — those first names are real Cloudflare NS hosts), but the A record is not in Cloudflare’s proxy ranges. DNS is at Cloudflare; stream traffic goes to the origin IP (grey-cloud).

Less likely to block the stream itself. Cloudflare is not sitting on the HTTP path, so they cannot WAF the MPEG-TS the way a proxy can. Residual risk: they still control DNS, so they can orange-cloud the hostname later without you changing the URL. Safer than Proxy for playback; still not as clean as a host with no Cloudflare badge.

Frequent failure

Frequent failure

This URL has gone down at least three separate times in the last 24 hours (not just one outage that lasted several check cycles). The monitor still probes it; failover will not pick a standby while it is currently DOWN.

Treat it as unreliable even if the latest card says UP — it has been flapping. Counts reset as those downs age out of the 24-hour window.
